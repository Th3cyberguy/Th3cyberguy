## Featured builds

### 🧠 MIMIR — multi-agent DFIR

Built for the SANS Find Evil! 2026 hackathon. Nine specialist agents investigate memory, disk, logs, network, and malware evidence through 33 forensic tools over MCP. Read-only evidence access, hash-chained tool logs, and human approval gates keep the investigation accountable. The private Python and Claude codebase has 541 tests.

### 🛡️ WinDEAS — Windows forensics

A PowerShell framework for Domain Controller forensics, detection automation, memory analysis, artifact collection, evidence preservation, and reporting. The repository is private; walkthroughs are available on request.

### 💊 Morpheus — private AI workspace

A self-hosted, Matrix-styled AI chat platform with project-based conversations, research modes, a skills framework that creates Word and PowerPoint files, and TOTP MFA. Built with FastAPI, React, TypeScript, and OpenAI-compatible APIs. The repository is private.

**Also exploring:** behavioral detection rules, evasion research, event correlation, and ways to reduce false positives.

## AI for defenders

What began as a 2025 homelab with LocalAI, Qdrant, RAG over Splunk logs, and n8n threat-intel workflows grew into Morpheus and then MIMIR. I'm now exploring case memory and local models for evidence-bound analytics.

- **Evidence first.** Findings should cite artifacts and explain the path to each conclusion.
- **Guardrails in the architecture.** Read-only evidence, allowlisted tools, and approval gates are controls the prompt cannot waive.
- **Humans make the call.** Agents triage, correlate, and draft; analysts approve consequential decisions.
